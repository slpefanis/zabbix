# Zabbix Templates

A collection of custom Zabbix monitoring templates, dashboards and integrations.

Templates are designed to be reusable, easy to maintain and focused on practical monitoring with minimal alert noise.

## Compatibility

Primarily developed and tested with **Zabbix 7.4**.

## Installation

1. Download the required template.
2. Import it into Zabbix.
3. Configure any required macros.
4. Link the template to a host.
